# dotfiles
My personal collection of config files for my Linux environments 

## Prerequisites

- [neovim](https://neovim.io): `rpm-ostree install nvim`
- [vicinae](https://github.com/vicinaehq/vicinae): `sudo dnf copr enable scottames/vicinae && rpm-ostree install vicinae`
- [hypridle](https://github.com/hyprwm/hypridle): `rpm-ostree install hypridle` 
- [hyprlock](https://github.com/hyprwm/hyprlock): `rpm-ostree install hyprlock`
- [waybar](https://github.com/Alexays/Waybar): `rpm-ostree install waybar`
- [JetBrains Mono](https://www.jetbrains.com/lp/mono/): `rpm-ostree install jetbrains-mono-fonts`
- [nwg-look](https://github.com/nwg-piotr/nwg-look): `rpm-ostree install nwg-look`
- [blueman](https://github.com/blueman-project/blueman): `rpm-ostree install blueman`
