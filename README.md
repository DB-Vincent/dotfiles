# dotfiles
My personal collection of config files for my Linux environments 

## Prerequisites
- [hyprland](https://github.com/hyprwm/Hyprland): `sudo dnf copr enable solopasha/hyprland && sudo dnf install hyprland`
- [neovim](https://neovim.io): `sudo dnf install nvim`
- [vicinae](https://github.com/vicinaehq/vicinae): `sudo dnf copr enable scottames/vicinae && sudo dnf install vicinae`
- [hypridle](https://github.com/hyprwm/hypridle): `sudo dnf install hypridle` 
- [hyprlock](https://github.com/hyprwm/hyprlock): `sudo dnf install hyprlock`
- [waybar](https://github.com/Alexays/Waybar): `sudo dnf install waybar`
- [JetBrains Mono](https://www.jetbrains.com/lp/mono/): `sudo dnf copr enable che/nerd-fonts && sudo dnf install nerd-fonts`
- [nwg-look](https://github.com/nwg-piotr/nwg-look): `sudo dnf install nwg-look`
- [blueman](https://github.com/blueman-project/blueman): `sudo dnf install blueman`
